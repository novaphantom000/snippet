# Snippet 📝

A lightweight, offline-first Android application for saving and organizing text snippets, code, and reusable messages.

## ✨ Features
- **Local Storage**: No cloud, no accounts, no internet required.
- **Organization**: Categorize snippets with custom colored tags.
- **Quick Access**: Pin important snippets to the top and mark favorites.
- **Search**: Real-time filtering of titles, content, and categories.
- **Material 3**: Built with the latest Material You expressive design guidelines.
- **One-Tap Copy**: Quickly copy content to clipboard with instant feedback.

## 🛠 Tech Stack
- **Language**: Kotlin
- **UI**: Jetpack Compose (Material 3)
- **Database**: Room SQLite
- **Architecture**: MVVM (Model-View-ViewModel)
- **State Management**: Kotlin Flows & StateFlow

## 🚀 Getting Started
1. Clone the repository.
2. Open the project in **Android Studio Flamingo** or newer.
3. Ensure you have the Android SDK 34 installed.
4. Run the app on an emulator or physical device.
